메인 루트

이 페이지는 태그를 사용해 만들 수 있는 모든 HTML 요소의 목록을 제공합니다. 필요로 하는 요소를 쉽게 찾을 수 있도록 기능별로 분류했으며, 각각의 요소 참조 페이지 사이드바에서는 사전 순으로 정렬된 목록도 확인할 수 있습니다.

요소 설명
html HTML 문서의 루트(최상위 요소)를 나타내므로 root 요소라고도 합니다. 다른 모든 요소는 이 요소의 자손이어야 합니다.

문서 메타데이터

메타데이터는 스타일, 스크립트, 각종 소프트웨어(검색 엔진, 브라우저 등)의 탐색 및 렌더링을 도와줄 데이터 등 페이지에 대한 정보를 가집니다. 스타일과 스크립트 메타데이터는 페이지 안에서 정의할 수도 있고, 해당하는 정보를 가진 다른 파일로 링크할 수도 있습니다.

요소 설명
base 문서의 모든 상대 URL에 사용할 기본 URL을 지정합니다. 문서에는 이러한 요소가 하나만 있을 수 있습니다.
head 제목, 스크립트 및 스타일 시트와 같은 문서에 대한 기계 판독 가능 정보(메타데이터)를 포함합니다.
link 현재 문서와 외부 리소스 간의 관계를 지정합니다. 이 요소는 CSS에 연결하는 데 가장 일반적으로 사용되지만 무엇보다도 사이트 아이콘("favicon" 스타일 아이콘과 홈 화면용 아이콘 및 모바일 장치의 앱)을 설정하는 데도 사용됩니다.
meta base, link, script, style, title과 같은 다른 메타관련 요소로 나타낼 수 없는 메타데이터를 나타냅니다.
style 문서 또는 문서의 일부에 대한 스타일 정보를 포함합니다. 이 요소를 포함하는 문서의 내용에 적용되는 CSS를 포함합니다
title browser의 제목 표시줄 또는 페이지의 탭에 표시되는 문서의 제목을 정의합니다. 텍스트만 포함합니다. 요소 내의 태그는 무시됩니다.

섹션 루트

요소 설명
body 문서의 본문을 나타내며, 실제 콘텐츠가 포함됩니다. body 요소는 html 요소의 자손이어야 하며, 문서에는 하나만 존재할 수 있습니다.

콘텐츠 섹션

콘텐츠 섹션은 문서의 구조를 정의하는 데 사용되는 요소입니다. 이러한 요소는 문서의 의미적 구조를 나타내며, 검색 엔진 최적화(SEO)와 접근성 향상에 도움을 줍니다.

요소 설명
address 가까운 HTML 요소의 사람, 단체, 조직 등에 대한 연락처 정보를 나타냅니다.
article 문서, 페이지, 애플리케이션, 또는 사이트 안에서 독립적으로 구분해 배포하거나 재사용할 수 있는 구획을 나타냅니다. 사용 예제로 게시판과 블로그 글, 매거진이나 뉴스 기사 등이 있습니다.
aside 문서의 주요 내용과 간접적으로만 연관된 부분을 나타냅니다. 주로 사이드바 혹은 콜아웃 박스로 표현합니다.
footer 가장 가까운 섹션 콘텐츠나 섹션 루트의 푸터를 나타냅니다. 푸터는 일반적으로 섹션의 작성자, 저작권 정보, 관련 문서 등의 내용을 담습니다.
header 소개 및 탐색에 도움을 주는 콘텐츠를 나타냅니다. 제목, 로고, 검색 폼, 작성자 이름 등의 요소도 포함할 수 있습니다.
h1, h2, h3, h4, h5, h6 문서의 제목을 나타냅니다. h1은 가장 높은 수준의 제목이고, h6은 가장 낮은 수준의 제목입니다. 제목 요소는 문서의 구조를 이해하는 데 도움을 줍니다.
main 문서의 주요 콘텐츠를 나타냅니다. main 요소는 문서에서 한 번만 사용해야 하며, 문서의 핵심 내용을 포함합니다.
nav 문서의 탐색 링크를 나타냅니다. nav 요소는 사이트 내의 다른 페이지나 섹션으로 이동할 수 있는 링크를 포함합니다.
section 문서의 일반적인 구획을 나타냅니다. section 요소는 제목을 포함할 수 있으며, 문서의 구조를 명확하게 나타내는 데 사용됩니다.

텍스트 콘텐츠

텍스트 콘텐츠는 문서의 내용을 구성하는 요소입니다. 이러한 요소는 텍스트를 구조화하고, 강조하며, 링크를 제공하는 데 사용됩니다.

요소 설명
blockquote 안쪽의 텍스트가 긴 인용문임을 나타냅니다. 주로 들여쓰기를 한 것으로 그려집니다. 인용문의 출처 URL은 <cite> 속성으로, 출처 텍스트는 <cite> 요소로 제공할 수 있습니다.
dd 정의 목록에서 용어의 설명을 나타냅니다. dd 요소는 dt 요소와 함께 사용됩니다.
div 유동 콘텐츠의 일반 컨테이너입니다. CSS를 사용하여 어떤 식으로든 스타일을 지정할 때까지 콘텐츠나 레이아웃에 영향을 미치지 않습니다(예: 스타일이 직접 적용되거나 flexbox와 같은 일종의 레이아웃 모델이 적용됨) 부모 요소.
dt 설명 혹은 정의 리스트에서 용어를 나타냅니다. <dl> 요소 안에 위치해야 합니다. 보통 <dd> 요소가 뒤따르지만, 여러 개의 <dt> 요소를 연속해 배치하면 바로 다음 <dd> 요소로 한꺼번에 서술할 수 있습니다.
figcaption figure 요소의 캡션(설명)을 나타냅니다. figcaption 요소는 figure 요소의 첫 번째 또는 마지막 자식으로 위치해야 합니다.
figure 독립적인 콘텐츠를 나타냅니다. figure 요소는 이미지, 그림, 도표, 코드 블록 등과 같은 미디어 콘텐츠를 포함할 수 있으며, figcaption 요소를 사용하여 설명을 추가할 수 있습니다.
hr 주제의 전환을 나타내는 구분선입니다. hr 요소는 시각적으로 구분선을 표시하며, 문서의 구조를 명확하게 나타내는 데 사용됩니다.
li 목록 항목을 나타냅니다. li 요소는 ul(순서 없는 목록), ol(순서 있는 목록), menu(메뉴 목록) 요소 안에 위치해야 합니다.
menu 사용자가 수행하거나 하는 명령 묶음을 말합니다. 이것은 스크린 위에 나오는 목록 메뉴와 눌려진 버튼 아래에 나오는 것과 같은 맥락 메뉴를 포함합니다.
ol 순서 있는 목록을 나타냅니다. ol 요소는 li 요소를 자식으로 포함하며, 각 항목은 순서대로 번호가 매겨집니다.
p 단락을 나타냅니다. p 요소는 텍스트를 구조화하고, 문서의 가독성을 향상시키는 데 사용됩니다.
pre 서식 있는 텍스트를 나타냅니다. pre 요소는 공백과 줄 바꿈을 유지하며, 코드 블록이나 시를 표시하는 데 사용됩니다.
ul 순서 없는 목록을 나타냅니다. ul 요소는 li 요소를 자식으로 포함하며, 각 항목은 점이나 다른 기호로 표시됩니다.

인라인 텍스트

인라인 텍스트 요소는 문서의 텍스트를 강조하거나 링크를 제공하는 데 사용됩니다. 이러한 요소는 블록 수준 요소와 달리 한 줄에 여러 개가 나란히 배치될 수 있습니다.

요소 설명
a 하이퍼링크를 나타냅니다. a 요소는 다른 페이지나 같은 페이지 내의 특정 위치로 이동할 수 있는 링크를 제공합니다.
abbr 약어를 나타냅니다. abbr 요소는 약어의 전체 의미를 제공하는 데 사용됩니다.
b 텍스트를 굵게 표시합니다. b 요소는 의미적 강조 없이 시각적으로만 강조할 때 사용됩니다.
bdi 텍스트의 방향을 격리하는 인라인 컨테이너입니다. bdi 요소는 양방향 텍스트에서 특정 텍스트의 방향을 독립적으로 설정하는 데 사용됩니다.
bdo 텍스트의 방향을 재정의합니다. bdo 요소는 dir 속성을 사용하여 텍스트의 방향을 설정할 수 있습니다.
br 줄 바꿈을 나타냅니다. br 요소는 텍스트를 다음 줄로 이동시키는 데 사용됩니다.
cite 작품의 제목을 나타냅니다. cite 요소는 책, 논문, 영화, 음악 작품 등의 제목을 표시하는 데 사용됩니다.
code 컴퓨터 코드를 나타냅니다. code 요소는 프로그래밍 코드나 명령어를 표시하는 데 사용됩니다.
data 기계 판독 가능한 데이터를 나타냅니다. data 요소는 사용자에게 표시되는 텍스트와 기계가 읽을 수 있는 값을 연결하는 데 사용됩니다.
dfn 용어의 정의를 나타냅니다. dfn 요소는 문서에서 처음 등장하는 용어를 정의할 때 사용됩니다.
em 텍스트를 강조합니다. em 요소는 의미적 강조를 제공하며, 일반적으로 이탤릭체로 표시됩니다.
i 텍스트를 이탤릭체로 표시합니다. i 요소는 의미적 강조 없이 시각적으로만 강조할 때 사용됩니다.
kbd 사용자가 입력하는 텍스트를 나타냅니다. kbd 요소는 키보드 입력, 음성 입력, 또는 다른 입력 장치를 통해 사용자가 제공하는 텍스트를 표시하는 데 사용됩니다.
mark 텍스트를 강조 표시합니다. mark 요소는 중요한 텍스트나 검색 결과에서 일치하는 텍스트를 강조하는 데 사용됩니다.
q 짧은 인용문을 나타냅니다. q 요소는 인용문을 표시하며, 일반적으로 따옴표로 감싸서 표시됩니다.
rp 루비 주석의 괄호를 나타냅니다. rp 요소는 루비 주석이 지원되지 않는 브라우저에서 괄호를 표시하는 데 사용됩니다.
rt 루비 주석의 텍스트를 나타냅니다. rt 요소는 루비 주석을 표시하는 데 사용됩니다.
ruby 루비 주석을 나타냅니다. ruby 요소는 한자나 일본어 등의 발음을 표시하는 데 사용됩니다.
s 텍스트에 취소선을 표시합니다. s 요소는 더 이상 유효하지 않거나 잘못된 텍스트를 나타내는 데 사용됩니다.
samp 컴퓨터 프로그램의 샘플 출력을 나타냅니다. samp 요소는 프로그램의 결과나 메시지를 표시하는 데 사용됩니다.
small 텍스트를 작은 크기로 표시합니다. small 요소는 보조적인 텍스트나 주석을 표시하는 데 사용됩니다.
span 인라인 컨테이너입니다. span 요소는 특정 텍스트를 그룹화하고 스타일을 적용하거나 스크립트로 조작할 때 사용됩니다.
strong 텍스트를 강하게 강조합니다. strong 요소는 의미적 강조를 제공하며, 일반적으로 굵은 글씨로 표시됩니다.
sub 텍스트를 아래 첨자로 표시합니다. sub 요소는 화학식이나 수학식에서 아래 첨자를 나타내는 데 사용됩니다.
sup 텍스트를 위 첨자로 표시합니다. sup 요소는 수학식이나 각주에서 위 첨자를 나타내는 데 사용됩니다.
time 날짜와 시간을 나타냅니다. time 요소는 기계 판독 가능한 날짜와 시간을 제공하며, 사용자에게 표시되는 텍스트와 연결할 수 있습니다.
u 텍스트에 밑줄을 표시합니다. u 요소는 의미적 강조 없이 시각적으로만 강조할 때 사용됩니다.
var 변수를 나타냅니다. var 요소는 수학식이나 프로그래밍 코드에서 변수를 표시하는 데 사용됩니다.
wbr 단어를 줄 바꿈할 수 있는 위치를 나타냅니다. wbr 요소는 긴 단어를 적절한 위치에서 줄 바꿈할 수 있도록 도와줍니다.

이미지 및 멀티미디어

이미지 및 멀티미디어 요소는 문서에 시각적, 청각적 콘텐츠를 포함하는 데 사용됩니다. 이러한 요소는 사용자 경험을 향상시키고, 정보를 효과적으로 전달하는 데 도움을 줍니다.

요소 설명
area 이미지 맵의 영역을 정의합니다. area 요소는 이미지 내에서 특정 영역을 클릭할 수 있도록 하며, 링크를 제공할 수 있습니다.
audio 오디오 콘텐츠를 나타냅니다. audio 요소는 음악, 음성, 효과음 등을 포함할 수 있으며, 브라우저에서 재생할 수 있습니다.
img 이미지를 나타냅니다. img 요소는 사진, 그림, 아이콘 등을 표시하는 데 사용됩니다.
map 이미지 맵을 정의합니다. map 요소는 이미지 내에서 클릭 가능한 영역을 지정하고, area 요소와 함께 사용됩니다.
track 비디오 및 오디오 콘텐츠에 대한 텍스트 트랙을 나타냅니다. track 요소는 자막, 설명, 챕터 등을 제공하는 데 사용됩니다.
video 비디오 콘텐츠를 나타냅니다. video 요소는 영화, 애니메이션, 동영상 등을 포함할 수 있으며, 브라우저에서 재생할 수 있습니다.
