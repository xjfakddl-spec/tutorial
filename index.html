학습 순서

  1. 1단계: HTML

    시맨틱 태그, 폼, 접근성 기본을 익혀 문서 구조를 정확히 만들기

  2. 2단계: CSS

    박스 모델, Flexbox, Grid, 반응형 레이아웃으로 화면 구성 능력 키우기

  3. 3단계: JavaScript

    문법, DOM 제어, 이벤트 처리, 비동기 처리(fetch, async/await) 익히기

  4. 4단계: React

    컴포넌트, 상태관리, 훅, 라우팅을 통해 SPA 구조 이해하기
